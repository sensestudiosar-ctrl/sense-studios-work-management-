## Reading this ledger

Each row maps the complete action list in the named feature-coverage family to its current application route/component and API root/controller family. “Capability/state evidence” names the authoritative place that must be checked for each specific operation. The prototype map's role labels are sample visibility only; they do not prove application permission. A controller file identifies the API owner, not by itself the effective permission, exact request payload, state transition, or UI availability. Those details remain open unless the feature-coverage representation and the named source operation have been individually compared. The 7 October coverage register is a prototype-representation inventory; the newer Owner acceptance direction in AGENTS.md controls slice status.

## G12 closure status

This ledger maps all action-family rows retained in the feature-coverage register to a current UI owner and API/controller family where one exists, and names the authoritative state/capability evidence class. It is a compact traceability index, **not a completed operation-by-operation acceptance ledger**: it does not claim that every individual action has a verified request schema, exact controller handler, service authorization predicate, before/after state, UI capability gate, error state, or successful interaction. The feature-coverage table remains the exact action-name inventory; use its action list together with the row above to identify the expected owner.

G12 therefore advances from “no operation ledger” to **partial — source-indexed ledger documented; exact per-operation contract audit and parity acceptance remain open**. Any row marked action-family representation or local fixture must not be promoted to production parity from this index. Explicitly missing/limited contracts are retained in the feature-coverage representation and the gap register; unsupported actions stop at the documented boundary rather than receiving a generic dialog.

No tests, typecheck, lint, build, browser checks, or API/database checks were run for this documentation update.
