## Key interactions

- Open a project, visit every section and return to the same directory filters/page.
- Create a Draft using existing template, scope, client and Won-lead rules; cancel safely and reopen confirmed results after a failed read.
- Open and close the same task from all four views. Preserve source view, filters, page, focus and scroll.
- Exercise Close, Escape, backdrop and browser Back with clean, dirty and pending forms.
- Use the phone Project section picker and all thirteen Kanban statuses. Verify zero counts describe this page only.

- Confirm lead and contributor selection independence. Distinguish inaccessible documents from an empty file register.

## Edge cases

- Direct task link without prior history; mismatched project/task ID; slow old request completing after project change.
- Session expiry or permission revocation while the panel is open; no previous task's protected content remains visible.
- Creation accepted with a lost response, confirmed creation with failed follow-up detail read, rapid double submission.
- Newly created task outside the current filters; its confirmed detail remains accessible without inventing membership in the visible page.
- Missing plan/lead/milestone, no authorized projects, no matching filters, partial Documents/Confirmed drawings results, failed review-summary read.
- Long names, task titles and status labels; keyboard-only use, screen reader names, 200% zoom and reduced motion.
