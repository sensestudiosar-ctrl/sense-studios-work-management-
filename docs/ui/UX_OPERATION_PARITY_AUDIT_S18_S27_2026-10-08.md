# S18 / S27 operation-level parity audit

**8 October 2026 — source trace only.** This addendum traces the S18 and S27 rows in `UX_VALIDATION_FEATURE_COVERAGE_2026-10-07.md` against the current API contracts and current web/API source, including current uncommitted Learning, Library, Training, Evidence Assistance and navigation edits. It does not change the operation-parity ledger or shared gap register. No tests, production operations, or new acceptance run were performed.

The coverage file's S18 row (line 40) inventories official ratings vs requests, exact publication/acknowledgement, and training review/recommendation; its S27 row (line 49) inventories bounded evidence requests, unranked candidates, reasoned decisions and ordinary-domain handoff. Its later “unavailable” statement (line 101) and IN PROGRESS labels are stale against current Owner direction: S18 and bounded S27 are accepted for development/local staging. This audit does not extend acceptance to actual-project R-104/R-105 use or production. Current code has authoring/assignment controls beyond the earlier prototype note that those flows were not demonstrated; these controls are traced below.

## Shared session, scope and UI states

- Learning routes are `/learning/skills`, `/learning/library`, `/learning/training` (and legacy `/learning`); Evidence Assistance is `/assistance`. Route/session guards and navigation are in [app.tsx](../../apps/web/src/app.tsx#L1349) and [app.tsx](../../apps/web/src/app.tsx#L1421). Learning navigation carries employee, record/version and assignment selection in query state.
- Reads use a current Owner/Staff session. Writes require same-origin and current CSRF; strict DTOs reject unknown fields. Skills/Library/Training writes use actor-scoped command receipts and recheck current session/scope. Same command and payload replays the result; changed payload conflicts.
- Learning and Library show inline loading/empty/notice/error states. Library clears inaccessible selected records on 403/404 and refreshes after failures. Training refreshes after writes and on 403/409. Evidence Assistance reauthorizes saved runs, removes inaccessible entries on 401/403/404 and asks for refresh on 409. These are source observations; this audit did not exercise them.
