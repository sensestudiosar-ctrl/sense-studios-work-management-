## Security and recovery matrix

| Scenario | Expected result |
| --- | --- |
| Foreign organization/branch/task/project/round/request | Denied/unavailable; no identifier/count leakage |
| Named reviewer versus submitter | Current independent reviewer action only |
| Approval expires/resolves/delegation ends after render | Command denies/conflicts under current policy; refresh removes obsolete action |
| Handler permits legitimate self-approval | Preserve that exception; no blanket invented ban |
| One source network/DB timeout | Mixed result unavailable/stale, independently known sources retained honestly |
| Malformed query/offset/limit | Strict bounded rejection, no privilege or count change |
| Version/capacity/parent conflict | Safe draft retained where appropriate; explicit refresh/resubmit |
| Session ends during loading/action/navigation | Protected state removed; late responses discarded |
| Local preference storage unavailable | Recoverable local preference message; commands still usable |
