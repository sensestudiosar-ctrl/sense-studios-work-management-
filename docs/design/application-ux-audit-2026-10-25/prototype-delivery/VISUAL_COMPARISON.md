The shell retains the existing My Work 232px sidebar foundation rather than importing a second shell. The four approved IA groups replace its older labels only in the prototype. Deeper destinations remain disclosed and scrollable. All pages use one shell and task detail behavior; there is one responsive navigation mode across the 767/768 boundary.

On phones, summaries become readable stacked rows instead of reproducing V10's horizontally scrolling summary cards. This keeps each label/count fully readable at 320px. Mobile work controls and project tabs target at least 44px; selected text, semantic error/warning colors and focus visibility take priority over exact screenshot imitation. The drawer becomes a full-width native modal with fixed actions and a scrollable body; latest review feedback precedes metadata. A fixed 44px close action avoids stretching alongside multi-line task titles.

The separate review harness replaces persona controls in product chrome. It labels synthetic state and never represents real authorization. Decorative icons and V10 page-finder/notification/account interactions are not duplicated just for visual resemblance; out-of-scope destinations are explicitly identified. Keyboard commands for a nonfunctional page finder are not advertised.
