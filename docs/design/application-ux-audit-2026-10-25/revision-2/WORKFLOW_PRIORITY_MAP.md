## Measurement convention

**N** counts navigation/selection actions from the stated starting point: opening a route, choosing a project/object, changing a section, or opening an action form. It excludes typing, scrolling, required evidence collection, required reasons and consequential confirmations/decisions. **C** lists context rebuilds; **F** lists field/decision groups, not raw DOM inputs. Phone More → destination adds one discovery action compared with a visible desktop link. Current counts are bounded path traces from actual read-only walkthroughs where available; source-only/unavailable paths are labeled. Target counts are design goals, not measured improvements.

Evidence codes: **O** prior actual Owner audit; **R** revision2 real backend STAFF session; **S** source contract; **B** absent role/state, blocked. Deep links can legitimately reduce the current count; the plan must not claim a reduction over that faster path.
